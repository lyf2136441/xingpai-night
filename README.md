# 星牌夜场 · 3D 联机原型

这是一个原创的手机浏览器 3D 社交生存游戏原型。核心体验是：在开放夜场里移动、寻找赌桌、由裁判匹配两名角色进行石头剪刀布，胜者夺取败者一颗星。

## 当前版本

- 280×280 的开放地图，活动空间约为早期原型的十倍以上；建筑有入口、墙体碰撞和门口交互点。
- 黑市、银行、裁判塔、无限监狱四个区域，以及六张带裁判的赌桌。
- 数据库驱动的人机角色：当前储备 20 个 NPC；人机可以自由探索、入桌、拒绝入桌、对局、被淘汰并被押入监狱。
- 每张赌桌有空闲、等待联机、匹配中、裁判倒计时、结算等状态。
- 手机摇杆、行动按钮、电脑 WASD/方向键均可操作。
- 手机端使用左下角遥感移动，右下角“行动”按钮拾取/入桌/交涉，旁边“视角”按钮循环切换镜头；触摸拖动画面可自由旋转视角。
- 房间最多 8 名真人玩家；联机房间缺少真人时，本地场景仍由人机补全活动。
- 联机对局由 WebSocket 服务同步，服务端负责房间、赌桌匹配和石头剪刀布结算。
- 联机入桌必须双方确认；双方只能在牌桌私聊和开启语音；联机回合可由服务器统一重开。
- 结盟、背叛、借贷、商店、每日签到、每日任务和虚拟金币系统。
- 星星归零后由裁判押入无限监狱；普通角色不能进入监狱，支付 300 虚拟金币才能赎回。
- 受击反馈使用彩色粒子、闪光和警报，不制作写实 gore。
- 增加城市天际线、道路标线、巡航无人机、远处四座地标、远景窗灯与屋顶信标、动态霓虹灯、镜头震动和移动端性能降级策略。
- 增加小地图、夜场轮换事件、活动播报、加载过渡和障碍物碰撞，让地图更容易理解和探索。
- 增加阶段目标 HUD：探索、补给、赌桌、关系交涉、监狱和安全离场会自动切换，并显示附近目标、宝物收集与区域探索进度；小地图会高亮最近的宝物。
- 四个功能区域支持靠近后按 E 调查：黑市打开商店、银行打开借贷、裁判塔展示规则观测信息，监狱对普通角色保持封锁。
- 提高环境光、月光、场馆灯、地面反差和远景可见度；保留血月、符文、霓虹和紫黑色调，但人物与道路更容易辨认。
- 大版本场景升级：区域入口门廊、动态光柱、中央环形步道、路灯、漂浮符文、赌桌牌阵、桌心能量盘和结算冲击波；V 键新增电影环绕视角。
- 人机具有赌徒、掮客、收藏家、观察者、调停者、黑市客、追猎者等身份，会主动寻找赌桌、功能区域和隐藏宝物，场内播报会显示他们的行动。
- 中央圆形广场增加权力高楼、夜场执掌人和楼顶远古计时钟；每个房间初始进行 30 分钟倒计时。
- 裁判只允许玩家使用自己的当前手牌进行对局，钟下实时显示房间牌库中石头、布、剪刀的剩余数量，右上角状态榜不显示他人星星或牌型。
- 每位玩家初始手牌为石头、布、剪刀各 2 张；平局消耗双方出牌，胜负也只消耗本次出牌；玩家只能在自己的 HUD 看到手牌。
- 推理社、会议室和夜场游乐园接入 `content-db.json`，当前储备 54 个事件、48 件宝物、35 个案件、18 个讨论议题和 24 个小游戏，并按历史去重轮换；每类内容完成一轮后才重新洗牌。
- 游乐园新增两张真实牌桌：暗夜二十一点支持下注、发牌、要牌、停牌、A 的 1/11 点数和庄家自动补牌；五张牌换牌局支持真实牌面、最多换两张、摊牌和高牌/对子/两对/三条/顺子/同花/葫芦/四条/同花顺判定，均有金币结算和再来一局。
- 游乐园室内地面增加材质层、灯带、墙面灯具和局部光源；室外游乐场增加分区地面、导视灯带与设施区域层次。
- “暗箱记忆牌阵”改为明确的五张可点击记忆牌：先观察上方四张目标顺序，5 秒后牌面翻面，再按顺序点击下方牌，错误会显示应点击的牌并结束本局。
- 室外游乐设施支持 3D 入座体验：靠近过山车、碰碰车或摩天轮后点击行动，角色会进入实体座舱；过山车/摩天轮镜头跟随运行，碰碰车可用 WASD、方向键或手机摇杆驾驶，行动键可随时下车。
- 新增雾港瞭望台、旧钟楼观景层等多层设施，场景内可乘电梯逐层上楼，顶层自动切换俯瞰镜头查看全局景色。
- 新增昼夜按钮：夜晚、白天、自动循环三种模式；会同步调整天空、雾、月光、血月和场馆灯光。
- 单机金币、手牌、宝物、借贷、位置和回合时间会保存在本机；“重新开局”会重置本回合但保留长期统计和内容轮换记录。

## 本地运行

需要 Node.js 18 或更高版本：

```powershell
npm install
npm start
```

联机闭环烟囱测试：

```powershell
npm run qa
```

该测试会验证数据库非空、两名玩家加入房间、双方确认入桌、暗牌对局扣牌，以及服务器重开回合后手牌恢复为 2/2/2。

然后打开：

```text
http://127.0.0.1:8787/index.html
```

Windows 可以双击 `启动游戏.cmd`。同一 Wi-Fi 下，手机访问启动脚本显示的局域网地址，例如：

```text
http://192.168.1.46:8787/index.html
```

手机和电脑需要连同一个 Wi-Fi，且 Windows 防火墙允许 Node.js 使用专用网络。

## Docker + HTTPS 部署

准备一台有公网 IP 的 Linux VPS，并将域名 A/AAAA 记录指向服务器。安装 Docker 和 Docker Compose 后，在项目目录执行：

```bash
cp .env.example .env
# 修改 .env，把 DOMAIN 改成你的真实域名
docker compose up -d --build
```

Caddy 会自动申请 HTTPS 证书，网页和 WebSocket 共用同一个域名；手机直接访问：

```text
https://你的域名/
```

公网联机不依赖手机和电脑处于同一个 Wi-Fi。所有玩家访问同一个公网域名，浏览器会通过 `wss://` 连接服务器房间；同一 Wi-Fi 只适用于本地测试。

访问 `http://127.0.0.1:8787/health` 可以检查服务、房间、玩家和内容库规模；当前内容库为 54 个事件、48 件宝物、48 个出生点、20 个 NPC、35 个案件、18 个会议议题和 24 个小游戏。

`Dockerfile` 会同时复制 `content-db.json` 和 `assets/`，避免云端镜像启动后内容库或音乐资源缺失。

当前工作区没有云平台账号、域名或部署令牌，也没有安装 Docker/Railway CLI，因此无法替你创建账号、完成短信验证或直接产生公网地址。你只需要提供已开通的 VPS/云平台和域名（不要把密码发在聊天里），我可以继续根据其控制台或部署令牌完成上线；公网 WebSocket 需要平台支持长连接。

服务器安全组只需要放行 TCP 80 和 443。游戏服务内部使用 8787，不需要把 8787 暴露到公网。

## 重要限制

当前版本是可玩的原型，房间和经济数据保存在内存中，服务器重启后会重置；要正式商业化，还需要数据库、账号系统、服务端完整经济校验、匹配队列、日志、限流和反作弊。

游戏金币是虚拟货币，不支持充值、提现或现金兑换；玩法和美术保持原创，不复制任何电影的角色、台词或专有场景。

## 两小时稳定性监测

Windows 可在服务启动后运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\long-run-monitor.ps1
```

监测脚本每分钟检查 `/health`、Node 服务进程和关键数据库数量，结果写入 `long-run-monitor.log`。本轮已启动后台监测，完成两小时后会在日志末尾写入 `END`。
